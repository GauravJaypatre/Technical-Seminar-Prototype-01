## 1. Provenance & Generation Mechanism

These artifacts were generated on **2026-09-07** during early scaffold development and checked in during the repository's initial commit (`54dbfef`, 2026-09-08). 

When Ollama or cloud LLM endpoints were unavailable (`_is_ollama_online() == False`), the early scaffold fell back to offline simulation functions:
* [`src/code_analyzer.py:141-160`](file:///c:/Users/HP/OneDrive/المستندات/Technical%20Seminar%20Prototype%2001/src/code_analyzer.py#L141-L160) (`_analyze_offline`): Simulated repair by drawing pseudo-random numbers against hardcoded probability arrays (`base_probs = {"easy": [0.45, 0.70, 0.90, 0.95, 0.95], ...}`). If the random draw passed, the problem's known `TASK_METADATA[task_id]["ground_truth_patch"]` was injected directly into the sandbox test runner. If it failed, a non-functional 3-line dummy diff (`-# Incomplete iteration ... / +# Attempt ...`) was emitted.
* [`src/monolithic_baseline.py:110-128`](file:///c:/Users/HP/OneDrive/المستندات/Technical%20Seminar%20Prototype%2001/src/monolithic_baseline.py#L110-L128) (`_generate_offline`): Similarly drew pseudo-random numbers (`0.40`, `0.20`, `0.08`) and injected the ground-truth patch upon success.
